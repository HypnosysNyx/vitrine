# Vitrine 1.0.0-beta.16 简体中文汉化版

> 🀄 **非官方社区汉化发布。** 对应 [Vitrine 原版 v1.0.0-beta.16](https://github.com/My-Name-Is-Jeff/vitrine/releases/tag/v1.0.0-beta.16)（2026-10-25）。本版保留原项目功能，在 [i18n/zh-hans](https://github.com/HypnosysNyx/vitrine/tree/i18n/zh-hans) 分支上增加简体中文 Mod 界面资源；**不代表原作者或 Spotify 官方发布**。

## 发布内容与原版保持一致

与原版相同，本 Release **不上传 IPA、DEB 或其他附加文件**。GitHub 自动提供的两个源码包是 **Source code (zip)** 与 **Source code (tar.gz)**，内容来自本汉化版本对应的 Git 标签。它们是源码，不是可直接安装的 iOS 应用。

如需使用，请按照 [完整中文版 README](https://github.com/HypnosysNyx/vitrine) 的步骤，使用自己合法取得的兼容 Spotify IPA 自行构建并签名。支持范围依原项目已验证的 Spotify 9.1.78、9.1.88、9.1.90 和对应 iOS 版本说明；未验证其他版本。

## 简体中文汉化说明

- 对 Vitrine 自有的 **Mod 设置、提示、部分播放器、歌词和卡拉 OK 控件、动态消息**等提供简体中文；不修改 Spotify 官方自有界面、系统文字、歌名或第三方网页。
- 汉化词库：[localization/zh-Hans.json](https://github.com/HypnosysNyx/vitrine/blob/i18n/zh-hans/localization/zh-Hans.json)；[汉化 QA 检查](https://github.com/HypnosysNyx/vitrine/actions/workflows/check-zh-hans.yml)。
- **源码质量检查与构建成功不代表完成全部机型的实机验证**。欢迎通过 [Issues](https://github.com/HypnosysNyx/vitrine/issues) 提供漏译截图、路径、设备型号、iOS/Spotify 版本及 Native/Redesigned 模式。
