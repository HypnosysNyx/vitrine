# Vitrine 简体中文汉化版 · 1.0.0-beta.16-zh.1

> 🇨🇳 **非官方简体中文社区汉化源码版本**。基于 [Vitrine 原项目](https://github.com/My-Name-Is-Jeff/vitrine) 的 `v1.0.0-beta.16` 及本仓库 `i18n/zh-hans` 的汉化改动，不是 Spotify 或 Vitrine 原作者的官方中文版。

## 下载与使用方式

**本 Release 不提供包含 Spotify 应用本体的 IPA，也不提供可直接安装的 DEB 或 IPA。** GitHub 自动生成的 **Source code (zip/tar.gz)** 是汉化源代码，**不是安装包**。

如要在 iPhone 上使用：

1. 阅读 [中文版 README](https://github.com/HypnosysNyx/vitrine) 的 [GitHub Actions 自行构建教程](https://github.com/HypnosysNyx/vitrine#方案-a-github-actions-在线构建)。
2. 使用 [`i18n/zh-hans` 汉化分支](https://github.com/HypnosysNyx/vitrine/tree/i18n/zh-hans) 中的 [Build IPA from your own Spotify IPA](https://github.com/HypnosysNyx/vitrine/actions/workflows/build-ipa.yml) 工作流。
3. 用户需**自行依法取得**版本兼容的 Spotify IPA，提供 HTTPS 下载地址并校验 SHA-256。
4. 完成编译后，从你自己的 Actions 构建记录下载 Artifact，再使用 SideStore、Feather 或其他合法签名安装工具签名安装。**Actions Artifact 并非永久下载地址。**

**注意：**原项目明确适配的 Spotify iOS 版本为 **9.1.78、9.1.88、9.1.90**。原生外观要求 **iOS 16.1+**，Liquid Glass 重设计推荐 **iOS 26+**，Live Activity 需要 **iOS 17+**。其他版本未作保证。

## 本版内容

- 简体中文 Mod 设置、提示说明、部分歌词与播放器控件、卡拉 OK、动态文本和错误信息。
- 保留 Vitrine 原有 Liquid Glass 重设计与原生界面模式，以及原项目提供的其他扩展功能。
- 不翻译 Spotify 官方应用全部页面、第三方原生页面、歌曲名及所有歌词；歌词翻译仍需可用的歌词源或翻译服务。
- 汉化词库：[localization/zh-Hans.json](https://github.com/HypnosysNyx/vitrine/blob/i18n/zh-hans/localization/zh-Hans.json)；[静态 QA、编译与回归](https://github.com/HypnosysNyx/vitrine/actions/workflows/check-zh-hans.yml)。

## 验证与风险

汉化分支已有 CI 静态检查及无 IPA 编译成功的历史记录，也曾执行过用户自行提供 IPA 的构建。**成功编译不代表所有 iPhone 实机页面无漏译或不存在崩溃**；请按实际使用反馈。

问题与漏译：[Issues](https://github.com/HypnosysNyx/vitrine/issues)。请提供设备、iOS/Spotify 版本、Native/Redesigned 模式、截图及操作路径，勿公开私人 IPA、证书、签名密码或登录令牌。
